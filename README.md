## Даалгавар 1: Дулаарлын тест

`T01` folder: `PUT /students/B231234567` (active, `["CS201"]`) → `PUT /courses/CS313` (`["CS201"]`) → `POST /registrations`. POST-ын oracle-ууд: `pm.response.to.have.status(201)` ба `body.result === "OK"`; нэмж `registrationID` нь эерэг бүхэл тоо эсэхийг (яг утгыг биш) шалгана. Хаяг нь collection variable `{{baseUrl}}` = `http://localhost:3000`.

## Даалгавар 2: Тест дизайн (Лекц 5-ын 5 алхам)

### Алхам 1 — Бие даан тестлэгдэх функц

`POST /registrations` — оюутныг хичээлд бүртгэх. Оролт: биеийн `studentID`, `courseID`; далд оролт (орчин): серверт тавьсан оюутны бичлэг (`status`, `coursesTaken`) ба хичээлийн бичлэг (`prerequisites`).

### Алхам 2–3 — Сонголтууд ба төлөөлөх утгууд

| Сонголт (параметр/орчин) | Утгын анги | Төлөөлөх утга | Хүлээгдэх нөлөө |
|---|---|---|---|
| **studentID-ийн хүчинтэй байдал** | Идэвхтэй | `B231234567`, `status:"active"` | Цааш шалгана |
|  | Идэвхгүй | `status:"inactive"` | ERROR_INACTIVE_STUDENT |
|  | Байхгүй | PUT хийгээгүй ID (`B23NOSTUDENT`) | ERROR_NO_STUDENT |
|  | Талбар дутуу (хязгаар) | биед `studentID` байхгүй | 400 ERROR_BAD_REQUEST |
| **Оюутны үзсэн хичээлүүд** (`coursesTaken`) | Урьдач нөхцөлийг хангана | `["CS201"]`, `["CS201","CS202"]` | Цааш шалгана |
|  | Хангахгүй | `[]` эсвэл `["CS101"]` | ERROR_PREREQUISITES |
|  | Хоосон (хязгаар) | `[]` | Урьдачгүй хичээлд OK |
| **courseID-ийн хүчинтэй байдал** | Байгаа | `CS313` (PUT хийсэн) | Цааш шалгана |
|  | Байхгүй | PUT хийгээгүй ID (`CS999`) | ERROR_NO_COURSE |
|  | Талбар дутуу (хязгаар) | биед `courseID` байхгүй | 400 ERROR_BAD_REQUEST |
| **Хичээлийн урьдач нөхцөл** (`prerequisites`) | Бүгдийг үзсэн | `["CS201"]` ба оюутан `["CS201"]` | 201 OK |
|  | Огт үзээгүй | `["CS201"]` ба оюутан `[]` | ERROR_PREREQUISITES, `missing:["CS201"]` |
|  | Зарим нь | `["CS201","CS202"]` ба оюутан `["CS201"]` | ERROR_PREREQUISITES, `missing:["CS202"]` |
|  | Урьдачгүй (хязгаар) | `[]` | 201 OK |
| **Хүсэлтийн формат** | Зөв JSON | `{"studentID":…,"courseID":…}` | Цааш шалгана |
|  | Буруу JSON (хязгаар) | `{"studentID": "B23` (дутуу) | 400 ERROR_BAD_JSON |

**Боломжгүй / утгагүй хослолууд:** оюутан *байхгүй* үед "үзсэн хичээлүүд" сонголт утгагүй (бичлэг байхгүй); хичээл *байхгүй* үед "урьдач нөхцөл" сонголт утгагүй; 400 (формат буруу) үед бусад бүх сонголт хамаагүй. Иймд эдгээрийг бүрэн үржвэрээр биш, давхар алдааны 2–3 сонирхолтой хослолоор л шалгана.

**Олон алдааны таамаг (тестээр тогтооно):** серверт оюутан хичээлээс өмнө шалгагдана гэж таамаглав: `400 формат → NO_STUDENT → INACTIVE → NO_COURSE → PREREQUISITES`. T07–T09 нь үүнийг баталгаажуулах тестүүд.
